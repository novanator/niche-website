# NICHE website

This is a public GitHub repository for https://niche.institute, hosted on GitHub Pages. Changes pushed to `main` deploy from the repository root.

## Public information only

- Treat every committed file, including this file and Git history, as publicly accessible. Files do not need to be linked from the homepage to be public.
- Never commit credentials, API keys, tokens, passwords, recovery codes, private personal information, or confidential organizational information.
- Keep private operational notes outside this repository. Publish only approved organizational facts; do not invent mission, programs, legal or tax-exempt status, contact details, or affiliations.
- Before committing, review the diff and staged files for sensitive information and unintended files.
- If sensitive information is found, do not copy it into commits, issues, or logs. Notify the user so exposed credentials can be revoked and the disclosure addressed; deleting a file alone does not remove it from Git history.
